# Client SDK

Клиент `openapi-fetch` типизирован сгенерированными OpenAPI paths из shared-types; transport wrapper добавляет CSRF из памяти и нормализует ошибки. DTO и пути не дублируются вручную. Operation polling будет добавлен с durable operations. Секреты провайдеров сюда не включаются.
