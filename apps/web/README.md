# Web UI

React, TypeScript, Vite, TanStack Query, React Router. Student/Teacher/Admin представления, realtime и Guacamole flow. Сервер остаётся источником прав и capacity.

Сейчас реализованы вход/регистрация/восстановление, группы, участники и административная выдача прав на группы. Realtime/Guacamole — следующие этапы. `npm run dev` / `npm run build` из корня; [инструкция](../../docs/local-start.md).

## Оформление

По запросу пользователя визуальный ориентир — [сайт ЮУТУ](https://suut.ural-campus.ru/). Основные токены в `src/style.css`: бирюзовый `#009f9b`, тёмный `#1e1e1e`, светлый фон, округлые карточки и кнопки. Для мелкого текста на светлом фоне используется более тёмный бирюзовый `#006d6a`.

Roboto и Unbounded подключаются из локальных пакетов Fontsource с кириллицей и латиницей; запросов к внешнему серверу шрифтов нет. Название Lab Manager и собственный знак сохранены. Изменения оформления проверены production build, двумя существующими Playwright-сценариями и просмотром desktop/mobile скриншотов.
